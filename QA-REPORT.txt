Manual steps before public launch
1. Run npm install, npm run typecheck and npm run build locally or use the GitHub Actions workflow.
2. Confirm guide.wishly.bd DNS and GitHub Pages custom domain, then enable HTTPS.
3. Test the live homepage, navigation, mobile layout, article links, 404, sitemap and ads.txt.
4. Verify the domain in Google Search Console and submit https://guide.wishly.bd/sitemap.xml.
5. Complete and maintain original editorial content. AdSense review and ranking are not guaranteed by technical setup alone.
6. After AdSense approval, either enable Auto Ads from the AdSense account or add real ad-slot IDs to public/assets/ads-config.js and enable the manual units.
